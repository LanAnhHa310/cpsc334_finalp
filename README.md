# cpsc334_finalp
Final Project for CPSC334

# Project Overview
Our project is a Python-based web scraper to help researchers and scholars find reputable research papers easily.

This is a web scraper which ensures that sources are correct and reputable search on google scholar. It will automatically search and collect reputable academic and scholarly sources from google scholar. Helps streamline the research process by extracting citation information, abstracts, and other details like publication details. 


# Deliverables
The deliverable is a structured CSV file that has verified scholarly references generated when the user wants. This will be main for researchers, analysts, students, etc who need rapid access to credible academic sources without browsing Scholar. 

# CI/CD Pipeline
We plan on using a GitHub Actions pipeline that automatically lints, tests, and verifies the scraper on every push changes to GitHub.
